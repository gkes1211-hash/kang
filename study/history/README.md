# 🧭 역사 탐험대

외우는 과목이 아니라 **이야기**로 한국사를 처음 만나게 하는 앱이에요. 휴대폰, 태블릿, 노트북에서 다 열려요.

**바로 열기: https://gkes1211-hash.github.io/kang/study/history/**

## 🎮 역사 속으로 (모험 편)

아이가 **시간 여행 탐험대원**이 되어 역사 인물 곁에서 중요한 순간마다 직접 골라요. 글 읽기를 줄이고 게임처럼 진행해요.

- 처음 한 번 **탐험대원 등록**: 별명, 모습(이모지), 말풍선을 소리 내어 읽어 줄지
- 한 편은 장면 10여 개(3~5분). 한 화면에는 장면 그림 + 짧은 말풍선 1~2줄 + 큰 선택 버튼
- 틀린 선택은 혼내지 않고 **"🤔 다시 생각해 볼까?"** + 힌트를 보여 준 뒤 다시 골라요
- 편마다 미니 놀이 (살수대첩: 🏃 지는 척 후퇴 7번 → 적 식량이 바닥, ⚔️ 적이 강을 반쯤 건넜을 때 공격)
- 끝나면 **📜 진짜 역사 카드**(언제·누가·누구와·어떻게 + 🔑 핵심 단어)와 인물 카드
- **🧠 기억 퀴즈**: 3일, 7일, 30일 뒤에 2문제씩 다시 물어봐요 (처음 화면에 알림). 다 맞히면 다음 단계로, 틀리면 같은 간격으로 한 번 더
- 별: 다시 생각한 횟수 2번까지 ⭐3, 5번까지 ⭐2, 그 위 ⭐1

지금 있는 모험: **살수대첩**. 새 모험은 `data/adventures.js` 에 더해요 (파일 위에 모양 설명, 테스트가 말풍선 길이 70자, 정답 보기 1개, 틀린 보기 힌트 등을 확인해요). 화면과 놀이는 `adventure.js`.

## 놀이 네 가지

| 놀이 | 하는 일 | 나중에 시험에 도움이 되는 점 |
| --- | --- | --- |
| 📖 이야기 듣기 | 짧은 이야기를 한 문단씩 열어 가며 읽어요. 🔊 **읽어 줘**를 누르면 소리 내어 읽고 다음 문단도 저절로 열어요. 끝에 "💬 너라면?"(정답 없는 질문)과 한 문제 퀴즈가 있어요 | 사건의 "왜?" |
| 🕵️ 나는 누구일까요? | 힌트 4개를 하나씩 열며 인물을 맞혀요. 첫 힌트에 맞히면 ⭐4, 마지막 힌트면 ⭐1 | 인물과 업적 |
| 🚂 연표 기차 | 사건 카드를 옛날 → 요즘 순서로 기차에 태워요. 틀리면 맞은 칸은 남고 틀린 칸만 내려요. 1단계(시대 순서) → 4단계(같은 시대 안 사건) | 시대 흐름(연표) |
| 🗂️ 인물 도감 | 맞힌 인물 카드가 모여요. 처음 화면의 🚂 시대 열차는 그 시대 인물이나 이야기를 만나면 칸에 불이 켜져요 | 전체 뼈대 |

처음 화면의 **오늘의 이야기**는 날마다 바뀌고, 아직 안 읽은 이야기부터 나와요.
기록(별, 도감)은 그 기기의 브라우저에만 저장돼요 (`localStorage` 의 `history5-v1`).

## 내용 더하기

내용은 모두 `data/` 폴더에 있어요. 파일 맨 위에 적는 방법이 있어요.

| 파일 | 내용 | 지금 |
| --- | --- | --- |
| `data/eras.js` | 시대 (시대 열차의 칸) | 8개 |
| `data/people.js` | 인물: 힌트 4개(어려운 것 → 쉬운 것), 맞힌 뒤 보여 줄 설명 | 24명 |
| `data/events.js` | 사건: 해(기원전은 음수), 한 줄 설명 | 25개 |
| `data/stories.js` | 이야기: 문단, "너라면?" 질문, 퀴즈 | 10개 |
| `data/words.js` | 낱말 사전: 힌트·설명·이야기·모험 글 속 어려운 낱말에 점선 밑줄, 누르면 뜻 카드(🔊 읽어 줘). 뜻에는 인물 이름을 쓰지 않아요(퀴즈 정답이 보이니까요) | 142개 |
| `data/adventures.js` | 모험 편: 장면, 선택, 미니 놀이, 진짜 역사 카드, 기억 퀴즈 | 1편 |

Claude Code에 "역사 탐험대에 ○○ 이야기 넣어 줘", "△△ 인물 추가해 줘"처럼 부탁해도 돼요.
고친 뒤에는 꼭 확인해요:

```bash
node study/history/tests/run.js
```

빈 칸, 겹치는 id, 힌트에 이름이 들어간 것, 같은 해에 사건이 둘인 것(연표 기차 정답이 둘이 돼요), 시대 순서가 거꾸로인 것, `sw.js`에 빠진 파일을 찾아 알려 줘요.

새 파일을 만들면 `index.html`과 `sw.js`의 `FILES`에 넣고, 앱을 고칠 때마다 `sw.js`의 `CACHE` 번호(`history5-v1`)를 올려요.
