# 🎈 꼬마 탐험대 공원 — 1~6학년 3D 공부 탐험

나무다리로 이어진 **섬마을**(공부 섬 · 놀이 섬 · 생활 섬 · 코딩 섬)의 건물 15곳에 들어가 **보물 상자 문제**를 풀고, 열쇠와 도장을 모아 **열기구를 타고 떠나는** 3D 게임이에요.
아이들이 각자 **1~6학년**을 고르면 같은 건물에서도 자기 학년에 맞는 문제가 나와요.

**▶ 바로 가기: https://gkes1211-hash.github.io/kang/study/kkoma-park/**

## 어떻게 놀아요?

1. 별명과 학년을 고르고, **내 캐릭터를 꾸며요** (얼굴·머리·옷·소품·같이 다니는 친구).
2. 가운데 **분수 광장 섬**에서 출발해 나무다리를 건너 각 섬으로 가요. 반짝이는 문으로 들어가면 건물 안 놀이방에서 동물 친구가 반겨 줘요. 오른쪽 위 **작은 지도**에서 건물 그림을 누르면 그 건물 앞으로 바로 가요.
3. 놀이방마다 **보물 상자 3개**의 문제를 풀면 🗝️ **열쇠**가 나타나요.
   - 처음 깬 건물은 **탐험 수첩에 도장**이 찍혀요.
   - 깬 건물에 다시 들어가면 **새 문제**가 나오고, 또 깨면 열쇠를 또 받아요.
4. 어느 건물이든 **도장 10개**를 모으면 분수 광장 옆 언덕의 **🎈 열기구 탈출장**이 열려요. 상자 4개에서 비밀번호 숫자를 찾으면 열기구를 타고 날아올라요!
5. 모은 **열쇠 수**에 따라 **특별한 꾸미기**가 하나씩 열려요 (🐥 병아리 1개 · ⭐ 별무늬 2 · 🦋 나비 날개 3 · 🐶 강아지 4 · 🦸 망토 5 · 🎩 마술사 모자 6 · 🐱 고양이 7 · 🪄 요술봉 8 · 🦖 공룡 모자 9 · ⚡ 번개무늬 10 · 🦸 영웅 가면 11 · 🐢 거북이 12 · 👑 왕관 14 · 🐉 아기 용 18).

## 🏘️ 건물을 늘리는 규칙

섬마을에는 앞으로도 건물이 계속 늘어나요. **"보너스 건물"을 따로 두지 않고** 새 건물도 원래 건물과 똑같이 대해요. 새 건물은 그 주제의 섬에 있는 **🌱 빈 땅**(코딩 섬은 **🚧 곧 열려요** 자리)에 들어가요.

- 어느 건물이든 처음 깨면 도장을 하나 받아요.
- 열기구는 **도장 10개**면 탈 수 있어요 (`content.js`의 `STAMPS_TO_FLY`). 건물이 늘어나도 이 숫자는 따로 정하지 않으면 그대로예요.
- 새 건물을 더하는 곳:
  - `content.js`: `SUBJECTS`에 한 줄(이름·동물 친구·인사말·`island`), `puzzlesFor`와 `finalPuzzles`에 문제
  - `content/`: 학년별 문제 파일
  - `buildings.js`: 생김새
  - `islands.js`: `SLOTS`에 자리 (빈 땅 하나를 `LOTS`에서 옮겨 쓰기), 섬을 늘리려면 `ISLANDS`·`BRIDGES`·`ROADS`
  - `world.js`: `INTERIOR`에 놀이방 꾸밈
  - `sw.js`: 오프라인 파일 목록

> 선생님 창을 닫거나 새로 고치면 수업이 끝나요. 아이가 잠깐 끊겨도 같은 탭에서 다시 들어오면 기록이 이어져요.

### 연결 방식과 개인정보

- 서버 없이 **기기끼리 바로 연결(WebRTC)** 해요. 서로를 찾을 때만 공개 연결 서버(`0.peerjs.com`)를 잠깐 써요.
- 주고받는 것은 **별명·학년·캐릭터 모습·위치·푼 문제 수·열쇠와 도장 수**뿐이고, 어디에도 저장되지 않아요.
- 튼튼 운동장의 카메라 영상은 그 기기 안에서만 써요.
- 학교 인터넷이 이런 연결을 막으면 "연결 서버에 닿지 못했어요"라는 안내가 나와요. 그때는 전산 담당 선생님께 `0.peerjs.com` 접속과 WebRTC 허용을 부탁하거나 혼자 놀기로 해 주세요.

## 문제 더 넣기

문제는 [`content/`](content) 폴더에 과목마다 있어요. 학년 목록에 한 줄씩 더하면 바로 나와요.

```js
C('곤충의 다리는 몇 개일까요?', ['6개', '4개', '8개', '10개'], 0, '곤충은 다리가 6개예요.'),   // 고르기 (정답 번호, 풀이)
X('달은 스스로 빛을 내요.', false, '햇빛을 반사해요.'),                                   // O/X
N('1m는 몇 cm일까요?', 100),                                                              // 숫자 자물쇠
O('계절 순서대로 놓아요.', ['봄', '여름', '가을', '겨울']),                                 // 순서대로 놓기
M('나라와 수도를 이어요.', [['일본', '도쿄'], ['프랑스', '파리']]),                         // 짝 맞추기
S('고체와 액체로 나눠요.', ['고체', '액체'], ['얼음', '돌'], ['물', '우유']),                // 나누어 담기
```

보기와 카드는 화면에 나올 때 섞이니까, 정답을 맨 앞에 써도 괜찮아요.
