# 5학년 2학기 수학 (노트북용)

아이 혼자 노트북으로 수학 문제를 풀고, 틀리면 왜 틀렸는지 알고 다시 푸는 앱이에요.
서버도 AI도 쓰지 않아요. 문제는 코드로 만든 "문제 틀"에서 숫자와 상황을 바꿔 끝없이 만들어요.

**바로 열기: https://gkes1211-hash.github.io/kang/study/math5/**

## 소단원의 세 가지 버튼

수학을 어려워하는 아이가 부담 없이 시작하도록, 기본 길과 도전 방을 나눴어요.
- 📘 **기본 → 응용 → 심화**: 문제집 형식 문제만 나와요. 기본부터 시작해서 처음 낸 답으로 3번 연속 맞히면 한 단계 위, 2번 연속 틀리면 한 단계 아래. 심화는 어려움·도전 난이도를 섞어요. 문제 화면의 "바꾸기"로 단계를 직접 고를 수도 있어요.
- 🧩 **사고력**: 그 소단원의 새로운 유형(O/X와 이유, 틀린 줄 찾기, 퍼즐, 주사위 …)만 나와요. 사고력 문제집 갈래(규칙 찾기, 논리·추론, 경우의 수, 공간 감각, 생활 속 문제)로 5단원은 11가지, 1·2·3·4·6단원은 모두 42가지를 더 넣었어요. 안에서 난이도 1~4가 자동 조절돼요.
- 🏔️ **최상위**: 문제집처럼 풀어요. 소단원의 대표 유형 목록에서 하나를 고르면 ① **대표 문제**를 힌트·풀이와 함께 한 단계씩 익히고(먼저 직접 풀어 봐도 돼요) ② 같은 유형을 비튼 **변형 문제 3개**에 도전해요. 3개 모두 맞히면 그 유형을 "정복"해요(`state.top`). 🌟 이야기 문제는 여러 내용을 이어서 푸는 긴 문제예요.
  - 🧭 **같이 풀기** (대표 문제): ① "방법 생각하기"에서 먼저 어떻게 풀지 떠올려요. 안 떠오르면 방법 힌트를 하나씩 받아요. ② "한 단계씩 풀기"에서 풀이를 한 줄씩 열고, 계산 결과 자리(□)를 아이가 직접 채워요. 한 번 틀리면 힌트, 두 번 틀리면 답을 보여 주고 다음 단계로 가요. ③ 다 풀면 같은 유형의 변형 문제 3개를 혼자서 풀어요. 처음부터 혼자 풀고 싶으면 "혼자 끝까지 풀어 볼래요"를 눌러요.
  - 코드: 풀이(`solution`)의 각 줄을 ' → '로 나누고, 조각마다 마지막 '= 값'이나 '이름: 값'을 □로 바꿔요(`core/guide.js`). 그래서 새 최상위 틀은 풀이를 "식 = 값" 꼴로 쓰면 저절로 같이 풀기가 돼요. 테스트가 모든 최상위 틀에서 □가 1개 이상 생기는지 확인해요.
  - 코드: 최상위 틀은 `tier: 'top'`, 이야기 문제는 `story: true`. `build(r, lv, v)`의 `v`는 0 = 대표 문제, 1~3 = 변형(`M5.topForm`으로 모양을 고름). 화면은 `app.js`의 `topList`, `topTopic`.
- 코드: `core/engine.js`의 `M5.modePool`, `createSession({ mode })` / 단계 기록은 `state.levels[소단원]`(1~3), 사고력은 `state.levels['소단원:think']`

## 문제집 오답 연습 (사진으로 받은 문제)

이 앱을 만든 가장 큰 이유예요. 아이가 문제집에서 틀렸거나 모르는 문제를 알고 넘어가게 해요.
1. 부모님이 문제집 사진을 Claude Code 대화에 올리고 "오답 세트 만들어 줘"라고 해요 (아이가 쓴 답, 틀림/모름을 적어 주면 더 정확해요).
2. Claude가 사진을 읽고 `homework/sets.js`에 세트를 추가해 main에 올려요. 사진 파일은 올리지 않고, 문제를 글·그림으로 옮겨 적어요.
   - 틀린 문제: 아이가 쓴 답으로 왜 틀렸는지(diagnosis) / 모르는 문제: 한 단계씩 여는 풀이
   - 틀린 표시만 있고 답이 문제집에 없을 때(연습장에 풀었을 때): 자주 하는 실수 목록(mistakes)을 넣어 두면, 앱에서 다시 풀 때 낸 답으로 원인을 찾아요
   - 연습 문제: 같은 유형의 검증된 문제 틀(tid)을 먼저, 맞는 틀이 없으면 직접 적은 문제(custom)
   - 정답 검산(check)을 꼭 넣고 `node tests/run.js`로 확인
3. 아이 화면: 홈의 "📸 문제집 오답 연습" → (틀린 문제) 한 번 더 풀기 → 왜 틀렸을까 → 풀이 한 단계씩 → 같은 유형 4번 연속 맞히기 → 1일·7일·30일 뒤 2문제씩 다시 확인
- 코드: `core/homework.js`(세트 등록·연습 문제 만들기), `app.js`의 hwList·hwIntro·hwExplain·hwPractice·hwCheck, 진행은 `state.hw`

- 약점 유형: 모서리 길이의 합, 보이지 않는 모서리, 주사위·전개도에서 마주 보는 면

## 3단원 합동과 대칭

문제집 사진(16~20번, 9~15번, 심화 3)의 문제 모양을 따라 만들었어요. 소단원 4개, 문제 틀 44개예요.
- 도형의 합동: 합동인 도형 고르기, 모눈에서 세기, 합동인 삼각형 쌍 세기, 합동인 삼각형 그리기 조건, 합동인 두 도형으로 자르기
- 합동인 도형의 성질: 대응점·대응변·대응각, 대응각 + 세 각(네 각)의 합, 종이띠 접기, 합동인 직사각형으로 만든 정사각형(서술형), 잘못 설명한 것 찾기
- 선대칭도형: 대칭축의 수, 대응변·대응각, 완성한 도형의 둘레(대칭축 위의 변 빼기), 대응점과 대칭축, 모눈에 점 찍어 완성하기
- 점대칭도형: 대응변·대응각, 둘레, 대칭의 중심, 완성한 도형의 넓이, 점 찍어 완성하기, 180° 돌린 디지털 숫자
- 약점 유형(자주 나와요): 대응각 + 각의 합, 완성한 도형의 둘레·넓이, 종이 접기, 디지털 숫자 돌리기
- 새 답 형식 `points`: 모눈 점을 눌러 찍는 문제. 정답을 보면 완성된 도형이 초록 점선으로 나와요.
- 새 그림: `geo`(꼭짓점 이름·길이·각·대칭축·모눈), `digits`(디지털 숫자, 180° 돌려 보기 단추)

## 4단원·6단원과 다양한 문제 스타일 (5단계)

- **4단원 소수의 곱셈** (소단원 4개, 틀 34개): (소수)×(자연수) / (자연수)×(소수) / (소수)×(소수) / 곱의 소수점 위치. 기본 계산, 실생활 문장제(마트 할인·kg당 가격·용돈·여행 거리·휘발유), □ 구하기, 서술형(분수로 바꾸기 / 자연수처럼 곱하기), 수 카드, 곱셈식 이용하기, 규칙 찾기, 거꾸로 문제
- **6단원 평균과 가능성** (소단원 4개, 틀 35개): 평균 / 평균 이용하기 / 가능성을 수로 나타내기 / 가능성 예상하고 판단하기. 표·막대그래프로 평균, 모르는 값 구하기, 목표 평균, 모둠 비교, 회전판·구슬 주머니, 가능성을 말과 수로
- **새 그림**: 막대그래프(지워진 막대 ? 포함), 회전판, 구슬 주머니
- **새 문제 스타일 (기획서 6번 B)** — 모든 단원에 넣었어요
  - O/X와 이유: 맞는지 판단하고 이유까지 함께 고르기
  - 틀린 줄 찾기: 친구 풀이에서 처음으로 틀린 줄 고르기
  - 퍼즐: 빈칸이 여러 개인 계산식, 조건 여러 개로 수 맞히기
  - 표·그래프 읽기, 생활 속 상황, 규칙 찾기, 어림 먼저, 거꾸로 문제
- 4단원 답은 소수 넷째 자리까지 나와요 (교과서에도 있는 범위). 나머지는 셋째 자리까지.
- 무한 모드: 문장 종류가 적은 틀(예: O/X와 이유)은 최근 50문제와 겹치면 다른 틀로 바꿔서 내요. 비슷한 문제 5개도 같은 틀로 새 문제를 못 만들면 같은 소단원의 다른 틀로 채워요.

## 2단원 분수의 곱셈 (4단계)

- 소단원 4개, 문제 틀 40개: (분수)×(자연수) / (자연수)×(분수) / 진분수의 곱셈 / (대분수)×(대분수) (세 분수의 곱셈 포함)
- **분수 입력칸**: 자연수 · 분자 · 분모 칸. 분자 칸에서 `/`를 누르면 분모 칸으로 가요.
- **약분 안내**: 값은 맞는데 약분을 끝까지 안 했거나 가분수로 쓰면 '틀림'이 아니라 "값은 맞았어요. 약분을 끝까지 했나요?"라고 안내하고 고치게 해요. (약점 2)
- **분수 표시**: 문제·보기·힌트의 분수를 교과서처럼 위아래로 쌓아서 보여 줘요.
- **그림 문제**: 정사각형·직사각형을 등분한 넓이 그림, 직사각형 넓이, 화살표 계산, 수 카드
- **서술형** (기획서 12번): 풀이 과정을 쓰고 답은 자동 채점 → 모범 풀이와 비교 → 체크리스트에서 체크하지 못한 단계는 개념 설명을 보여 줘요.
- 약점 문제: "나머지의", "그중"이 나오는 문장제, 공이 둘째·셋째로 튀어 오른 높이 (약점 1), 단위분수 크기 비교 □ 문제 (약점 3)

## 틀렸을 때의 흐름 (3단계)

1. **어디서 틀렸을까?** 정답은 아직 보여 주지 않고, 아이가 먼저 원인을 골라요. (개념을 몰랐어요 / 계산하다 실수했어요 / 문제를 잘못 읽었어요 / 잘 모르겠어요)
2. **앱이 찾은 원인.** 아이 답을 오답 패턴과 비교해서 진짜 원인을 알려 줘요. 아이가 고른 원인과 다르면 그것도 알려 줘요. 맞는 패턴이 없으면 "어디서 다른지 같이 찾아볼까요?" 하고 힌트 1부터 줘요.
3. **개념 설명**이 열려요.
4. **같은 문제 다시 풀기.** 틀릴 때마다 힌트가 하나씩 늘어요(최대 3단계). 그래도 틀리면 정답과 풀이를 보여 주고, 직접 따라 입력하게 해요.
5. **비슷한 문제 5개 도전.** 같은 틀 3개 + 같은 원인의 오답 패턴을 가진 같은 소단원의 다른 틀 2개예요. (원인을 못 찾았으면 5개 모두 같은 틀) 도전 중에는 정답을 보여 주지 않아요.
   - 4개 이상 맞히면 **"이 유형 통과" 도장**을 받고 무한 모드로 돌아가요.
   - 3개 이하면 틀린 문제를 하나씩 1~4번으로 고친 뒤, 새 문제 5개로 한 번 더 도전해요.
   - 두 번째도 3개 이하면 **"다음에 다시 도전"** 목록에 넣고 무한 모드로 돌아가요. 나중에 그 유형을 통과하면 목록에서 빠져요.

기록: 받은 도장, 다음에 다시 도전 목록, 유형별로 틀린 횟수, 실제 원인과 아이가 고른 원인이 저장돼요. (7단계 "내 기록"과 복습에 써요)

## 2단계에서 만든 것

- 1단원 수의 범위와 어림하기: 소단원 7개, 문제 틀 62개
- 무한 모드: 문제집 형식 약 60%, 새로운 유형 약 40%. 같은 스타일이 3번 연속 나오지 않고, 최근 50문제와 겹치지 않아요
- 난이도 4단계 (쉬움·보통·어려움·도전): 3문제 연속 맞히면 한 단계 위로, 2문제 연속 틀리면 한 단계 아래로
- 채점: 0.50과 0.5를 같게, 여러 개 답은 순서 상관없이, 빠진 수와 남는 수를 구분해서 알려 줘요
- 20문제마다 쉬어 가기, 그만 풀기를 누르면 오늘의 결과
- "문제가 이상해요" 버튼: 그 문제는 채점에서 빼고 저장 (홈 화면 맨 아래에서 확인)

## 노트북에서 열기

1. 이 폴더(`study/math5`)를 노트북에 내려받아요.
2. `index.html`을 두 번 클릭하면 크롬이나 엣지에서 열려요.

학습 기록은 그 노트북의 그 브라우저 안에 저장돼요.

## 자동 테스트

[Node.js](https://nodejs.org)(LTS)를 설치한 뒤 저장소 맨 위 폴더에서:

```bash
node study/math5/tests/run.js
```

틀마다 문제 1000개를 만들어서 확인해요.

- 정답이 문제 조건을 실제로 만족하는지 (만드는 방법과 다른 방법으로 다시 계산)
- 정답을 넣으면 맞았다고 채점하는지
- 오답 패턴 값이 정답과 같지 않은지, 넣으면 원인을 찾아내는지
- 객관식 선택지가 겹치지 않는지
- 음수, 너무 큰 수, 너무 긴 소수가 없는지
- 분수 답은 기약분수이고 분모가 100 이하인지, 약분하지 않은 답·가분수 답에 '틀림'이 아니라 안내가 나오는지
- 힌트 3단계, 풀이, 개념 설명, 그림, 서술형 체크리스트가 모두 있는지, 분수 표시와 조사가 깨지지 않았는지
- 무한 모드의 문제 섞기와 난이도 조절이 규칙대로인지
- 비슷한 문제 5개가 겹치지 않고, 같은 소단원·같은 난이도이고, 다른 틀에서 가져온 문제는 같은 원인의 오답 패턴을 가졌는지
