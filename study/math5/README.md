# 5학년 2학기 수학 (노트북용)

아이 혼자 노트북으로 수학 문제를 풀고, 틀리면 왜 틀렸는지 알고 다시 푸는 앱이에요.
서버도 AI도 쓰지 않아요. 문제는 코드로 만든 "문제 틀"에서 숫자와 상황을 바꿔 끝없이 만들어요.

## 지금 되는 것 (2단계)

- 1단원 수의 범위와 어림하기: 소단원 7개, 문제 틀 62개
- 무한 모드: 문제집 형식 약 60%, 새로운 유형 약 40%. 같은 스타일이 3번 연속 나오지 않고, 최근 50문제와 겹치지 않아요
- 난이도 4단계 (쉬움·보통·어려움·도전): 3문제 연속 맞히면 한 단계 위로, 2문제 연속 틀리면 한 단계 아래로
- 채점: 0.50과 0.5를 같게, 여러 개 답은 순서 상관없이, 빠진 수와 남는 수를 구분해서 알려 줘요
- 틀리면: 틀린 원인(개념·계산 실수·조건 놓침)과 개념 설명 → 다시 풀기 → 틀릴 때마다 힌트 1·2·3단계 → 그래도 틀리면 정답과 풀이
- 20문제마다 쉬어 가기, 그만 풀기를 누르면 오늘의 결과
- "문제가 이상해요" 버튼: 그 문제는 채점에서 빼고 저장 (홈 화면 맨 아래에서 확인)

## 노트북에서 열기

1. 이 폴더(`study/math5`)를 노트북에 내려받아요.
2. `index.html`을 두 번 클릭하면 크롬이나 엣지에서 열려요.

학습 기록은 그 노트북의 그 브라우저 안에 저장돼요.

## 자동 테스트

[Node.js](https://nodejs.org)(LTS)를 설치한 뒤 저장소 맨 위 폴더에서:

```bash
node study/math5/tests/run.js
```

틀마다 문제 1000개를 만들어서 확인해요.

- 정답이 문제 조건을 실제로 만족하는지 (만드는 방법과 다른 방법으로 다시 계산)
- 정답을 넣으면 맞았다고 채점하는지
- 오답 패턴 값이 정답과 같지 않은지, 넣으면 원인을 찾아내는지
- 객관식 선택지가 겹치지 않는지
- 음수, 너무 큰 수, 너무 긴 소수가 없는지
- 힌트 3단계, 풀이, 개념 설명, 그림이 모두 있는지
- 무한 모드의 문제 섞기와 난이도 조절이 규칙대로인지

## 폴더 구조

```
index.html  style.css  app.js     화면
core/        rand.js    무작위 수
             dec.js     소수를 정수로 바꿔 정확하게 계산, 올림·버림·반올림
             text.js    조사(이/가, 을/를) 붙이기, 쉼표, 자리 이름
             grade.js   채점
             engine.js  문제 틀 등록, 문제 만들기, 무한 모드·난이도
             store.js   기록 저장 (localStorage)
templates/   words.js   이름·물건 목록
             u1-range.js  1단원: 이상·이하 / 초과·미만 / 수의 범위 활용
             u1-round.js  1단원: 올림 / 버림 / 반올림 / 어림 활용
draw/        figure.js  수직선·수 카드·표 그리기
tests/       run.js     자동 테스트
```

새 단원을 추가할 때는 `templates/`에 단원 파일을 만들고 `index.html`에 한 줄 추가하면 돼요.
자동 테스트도 `index.html`에 적힌 파일을 그대로 읽어서 검사해요.
