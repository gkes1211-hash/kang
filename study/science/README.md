# 🔬 과학 실험실

과학을 어려워하는 아이가 **예상하고, 화면 속 실험을 직접 해 보고, 용어 카드를 모으며** 학기 과학을 다시 공부하는 앱이에요. 노트북(마우스) 기준이에요.

**▶ 주소: https://gkes1211-hash.github.io/kang/study/science/**

## 한 판 (10분쯤, 하루 한 판)

🤔 예상 → 🧪 해 보기 → 👀 관찰 → 💡 알게 된 것 (🃏 용어 카드) → ⭐ 퀴즈 3개

- 예상은 틀려도 괜찮아요. 실험으로 확인하는 게 과학이에요.
- 틀리면 힌트 → 보기 줄이기 → 정답을 보여 주고 넘어가요. 별은 줄어도 0개는 없어요.
- 말풍선은 🔊 버튼(또는 위의 "읽어 주기 켜짐")으로 소리 내어 읽어 줘요. 기기에 한국어 목소리가 있어야 해요.
- 기록(별, 끝낸 실험, 카드)은 그 기기의 브라우저에만 저장돼요.

## 파일

```
science/
├─ index.html  app.js (화면·한 판 흐름)  lab.js (실험 장치)  style.css
├─ data/5-2/index.js   학기: 단원과 실험 차례
├─ data/5-2/u1.js      1단원 실험 5판 + 용어 카드 + 단원 마무리
├─ tests/run.js        데이터 검사: node study/science/tests/run.js
└─ sw.js  manifest.webmanifest  install.js  icons/
```

- **단원 더하기**: `data/5-2/u2.js` 를 `u1.js` 모양대로 만들고, `index.html` 과 `sw.js` FILES 에 한 줄씩 더해요. 실험 장치가 새로 필요하면 `lab.js` 에 더해요.
- **학기 더하기 (예: 6학년 1학기)**: `data/6-1/index.js` 를 만들면 처음 화면 위쪽 학기 고르기에 나타나요.
- 말풍선 글은 70자 이하, 문제의 정답은 `choices` 의 첫 번째 (화면에서 섞어요). 고친 뒤에는 `node study/science/tests/run.js` 를 돌려요.
- 파일을 고치면 `sw.js` 의 `CACHE` 숫자를 하나 올려요.
