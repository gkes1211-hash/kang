# 🎈 꼬마 탐험대 공원 — 1~6학년 3D 공부 탐험

공원 곳곳의 놀이 구역에서 **보물 상자 문제**를 풀고, 열쇠와 도장을 모아 **열기구를 타고 떠나는** 3D 게임이에요.
아이들이 각자 **1~6학년**을 고르면 같은 구역에서도 자기 학년에 맞는 문제가 나와요.

**▶ 바로 가기: https://gkes1211-hash.github.io/kang/escape/**

## 어떻게 놀아요?

1. 별명과 학년을 고르고, **내 캐릭터를 꾸며요** (얼굴·머리·옷·소품·같이 다니는 친구).
2. **만남의 분수 광장**에서 아치 문을 지나 놀이 구역으로 들어가요. 구역마다 동물 친구가 반겨 줘요.
3. 구역마다 **보물 상자 3개**의 문제를 풀면 🗝️ **열쇠**가 나타나요.
   - 처음 깬 구역은 **탐험 수첩에 도장**이 찍혀요.
   - 깬 구역에 다시 들어가면 **새 문제**가 나오고, 또 깨면 열쇠를 또 받아요.
4. **도장 9개**(모든 구역)를 모으면 광장 뒤 **🎈 열기구 탈출장**이 열려요. 상자 4개에서 비밀번호 숫자를 찾으면 열기구를 타고 날아올라요!
5. 모은 **열쇠 수**에 따라 **특별한 꾸미기**가 하나씩 열려요 (🐥 병아리 1개 · ⭐ 별무늬 2 · 🦋 나비 날개 3 · 🐶 강아지 4 · 🦸 망토 5 · 🎩 마술사 모자 6 · 🐱 고양이 7 · 🪄 요술봉 8 · 🦖 공룡 모자 9 · ⚡ 번개무늬 10 · 🦸 영웅 가면 11 · 🐢 거북이 12 · 👑 왕관 14 · 🐉 아기 용 18).

| 🌈 무지개 물감 언덕 🦊 | 미술 | 물감 섞어 색 만들기, 색의 성질·화가와 작품 |

- 💡 힌트: 한 번 누르면 귀띔, 두 번 누르면 틀린 답을 지워 주거나 한 칸을 대신 채워 줘요.
- 🔊 문제 읽어 주기: 1·2학년은 문제를 자동으로 읽어 줘요.
- 같은 구역에 다시 들어가도 바로 전에 나온 문제는 다시 나오지 않아요.
- 모은 열쇠·도장은 이 기기에 **별명 + 학년**마다 저장돼요. 꾸민 모습은 별명마다 저장돼요.

## 🧑‍🏫 반 전체가 함께하기 (20명 넘게 동시에)

1. 선생님 컴퓨터(교실 TV·전자칠판에 연결하면 좋아요)에서 **"🧑‍🏫 선생님: 공원 열기"**를 눌러요.
2. 화면에 큰 **수업 코드 4자리**가 나와요.
3. 아이들은 각자 태블릿에서 별명·학년을 고르고 숫자 4개를 넣은 뒤 **"🎒 친구들과 들어가기"**를 눌러요.
4. 같은 구역에 있는 친구들의 캐릭터가 보이고, 😀🎉 같은 기분 표현을 주고받아요. (자유 채팅은 없어요.) 친구가 열쇠를 찾으면 색종이가 터져요.

선생님 화면: 광장·구역·열기구를 골라 3D로 내려다보기, 아이마다 학년·지금 있는 곳·도장·열쇠·맞힘·틀림·힌트 보기, 📢 알림, ⏸️ 모두 멈춰!, 🏠 모두 광장으로, 🏆 순위 발표, 내보내기, 수업 끝내기.

> 선생님 창을 닫거나 새로 고치면 수업이 끝나요. 아이가 잠깐 끊겨도 같은 탭에서 다시 들어오면 기록이 이어져요.

### 연결 방식과 개인정보

- 서버 없이 **기기끼리 바로 연결(WebRTC)** 해요. 서로를 찾을 때만 공개 연결 서버(`0.peerjs.com`)를 잠깐 써요.
- 주고받는 것은 **별명·학년·캐릭터 모습·위치·푼 문제 수·열쇠와 도장 수**뿐이고, 어디에도 저장되지 않아요.
- 튼튼 운동장의 카메라 영상은 그 기기 안에서만 써요.
- 학교 인터넷이 이런 연결을 막으면 "연결 서버에 닿지 못했어요"라는 안내가 나와요. 그때는 전산 담당 선생님께 `0.peerjs.com` 접속과 WebRTC 허용을 부탁하거나 혼자 놀기로 해 주세요.

### 느린 태블릿

화면이 버벅이면 게임이 스스로 화질을 낮춰요 (선명함 → 그림자 끄기 순서).

## 문제 더 넣기

문제는 [`content/`](content) 폴더에 과목마다 있어요. 학년 목록에 한 줄씩 더하면 바로 나와요.

```js
C('곤충의 다리는 몇 개일까요?', ['6개', '4개', '8개', '10개'], 0, '곤충은 다리가 6개예요.'),   // 고르기 (정답 번호, 풀이)
X('달은 스스로 빛을 내요.', false, '햇빛을 반사해요.'),                                   // O/X
N('1m는 몇 cm일까요?', 100),                                                              // 숫자 자물쇠
O('계절 순서대로 놓아요.', ['봄', '여름', '가을', '겨울']),                                 // 순서대로 놓기
M('나라와 수도를 이어요.', [['일본', '도쿄'], ['프랑스', '파리']]),                         // 짝 맞추기
S('고체와 액체로 나눠요.', ['고체', '액체'], ['얼음', '돌'], ['물', '우유']),                // 나누어 담기
```

보기와 카드는 화면에 나올 때 섞이니까, 정답을 맨 앞에 써도 괜찮아요.

| `app.js` | 게임 흐름: 꾸미기, 구역·상자·열쇠·도장, 특별 꾸미기 열기, 열기구, 함께하기, 선생님 화면 |

| `puzzles.js` | 퍼즐 화면 13가지 |
| `content.js`, `content/` | 놀이 구역과 과목·학년별 문제 |
