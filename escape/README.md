# 🗝️ 열쇠 학교 — 3D 공부 방탈출

수수께끼에 잠긴 학교에서 **과목 교실 9곳**의 상자를 열고 열쇠를 모아 **옥상으로 탈출**하는 3D 게임이에요.
아이들이 각자 **1~6학년**을 고르면 같은 교실에서도 자기 학년에 맞는 문제가 나와요.

**▶ 바로 가기: https://gkes1211-hash.github.io/kang/escape/**

## 📲 열쇠 학교 아이콘 만들기 (따로 여는 앱)

체육시간과 따로, 열쇠 학교만 여는 아이콘을 만들 수 있어요.

- **안드로이드·크롬·엣지**: 열쇠 학교 첫 화면의 **📲 열쇠 학교 앱 설치하기** 단추를 누르거나, 주소창 메뉴 → "앱 설치"
- **아이패드·아이폰 사파리**: 공유 버튼 → **홈 화면에 추가**
- **윈도우 바탕화면**: 첫 화면 아래 **💻 윈도우 바탕화면 아이콘 받기**를 눌러 압축 파일을 받아요.
  (또는 저장소의 [`desktop-shortcut/yeolsoe-desktop-shortcut.zip`](desktop-shortcut/yeolsoe-desktop-shortcut.zip) → Download)
  압축을 풀고 **`make-shortcut.bat`**을 두 번 누르면 바탕화면에 **열쇠 학교** 아이콘이 생겨요.
  ("Windows의 PC 보호" 창이 나오면 "추가 정보" → "실행")

## 어떻게 놀아요?

1. 이름(별명), 학년, 옷 색깔을 고르고 들어가요.
2. 복도를 걸어 다니다 교실 문 앞에서 단추를 눌러요. (화면을 누르면 그곳으로 걸어가요. 문이나 상자를 누르면 걸어가서 열어요.)
3. 교실마다 **상자 3개**의 문제를 풀면 가운데에 🗝️ 열쇠가 나타나요.
4. 열쇠를 **5개** 모으면 복도 가운데 계단 위 **옥상 문**이 열려요.
5. 옥상에서 상자 4개를 풀면 숫자가 하나씩 나와요. 그 숫자로 **탈출구 비밀번호**를 맞히면 탈출 성공! 🎉

| 교실 | 퍼즐 |
| --- | --- |
| 📖 국어 · 🌏 사회 · 🔬 과학 | 고르기, 순서대로 놓기 (1·2학년 사회·과학은 통합교과 내용) |
| ➗ 수학 | 학년에 맞는 계산 문제를 그때그때 새로 만들어요 (숫자 자물쇠) |
| 🔤 영어 | 원어민 목소리 듣고 고르기, 철자 맞추기, 표현 고르기 |
| 🎵 음악 | 계이름대로 건반 치기, 음악 상식 |
| 🎨 미술 | 물감 섞어 색 만들기, 미술 상식 |
| ⚽ 체육 | **카메라**로 스쿼트·팔 벌려 뛰기 세기 (카메라 없이 스스로 세기도 돼요), 안전 상식 |
| 💻 코딩 | 블록으로 로봇을 열쇠까지 (1·2학년 화살표 → 3·4학년 돌기 → 5·6학년 반복) |

- 💡 힌트: 한 번 누르면 귀띔, 두 번 누르면 틀린 답을 지워 주거나 한 칸을 대신 채워 줘요.
- 🔊 문제 읽어 주기: 1·2학년은 문제를 자동으로 읽어 줘요.
- 모은 열쇠는 기기에 **이름+학년**별로 저장돼요.

## 🧑‍🏫 반 전체가 함께하기 (20명 넘게 동시에)

1. 선생님 컴퓨터(교실 TV·전자칠판에 연결하면 좋아요)에서 열쇠 학교를 열고 **"🧑‍🏫 선생님: 수업 열기"**를 눌러요.
2. 화면에 큰 **수업 코드 4자리**가 나와요.
3. 아이들은 각자 태블릿에서 학년을 고르고 수업 코드를 넣은 뒤 **"👫 수업에 들어가기"**를 눌러요.
4. 같은 교실에 있는 친구들이 3D 화면에 보이고, 😀🎉 같은 기분 표현을 주고받을 수 있어요. (자유 채팅은 없어요.)

선생님 화면에서 할 수 있는 것:

- 🎥 복도·교실·옥상을 골라 아이들이 어디서 무얼 하는지 3D로 내려다보기
- 📋 아이마다 학년, 지금 있는 곳, 모은 열쇠, 맞힘·틀림·힌트 수 보기
- 📢 알림 보내기, ⏸️ 모두 멈춰!, 🏠 모두 복도로, 🏆 순위 발표, ✕ 내보내기, 수업 끝내기

> 선생님 창을 닫거나 새로 고치면 수업이 끝나요. 수업 중에는 선생님 컴퓨터가 잠들지 않게 해 주세요.
> 아이가 잠깐 끊겨도 같은 탭에서 다시 들어오면 기록이 이어져요.

### 연결 방식과 개인정보

- 서버 없이 **기기끼리 바로 연결(WebRTC)** 해요. 서로를 찾을 때만 공개 연결 서버(`0.peerjs.com`)를 잠깐 써요.
- 주고받는 것은 **별명·학년·옷 색·위치·푼 문제 수**뿐이에요. 어디에도 저장되지 않아요.
- 체육관 카메라 영상은 그 기기 안에서만 써요. 어디로도 보내지 않아요.
- 학교 인터넷이 이런 연결을 막으면 "연결 서버에 닿지 못했어요"라는 안내가 나와요. 그때는 학교 전산 담당 선생님께 `0.peerjs.com` 접속과 WebRTC 허용을 부탁하거나, 혼자 하기로 해 주세요.

## 문제 더 넣기

문제는 모두 [`content.js`](content.js)에 있어요. 학년별 목록에 한 줄씩 더하면 바로 나와요.

```js
// 고르기: C(문제, [보기...], 정답 번호(0부터), 풀이)
C('곤충의 다리는 몇 개일까요?', ['6개', '4개', '8개', '10개'], 0, '곤충은 다리가 6개예요.'),
// 숫자 자물쇠: N(문제, 정답 숫자)
N('1m는 몇 cm일까요?', 100),
// 순서대로 놓기: O(문제, [맞는 순서...])
O('계절 순서대로 놓아요.', ['봄', '여름', '가을', '겨울']),
```

보기는 화면에 나올 때 섞이니까, 정답을 맨 앞(0번)에 써도 괜찮아요.
