# 여행 영어 첫걸음 ✈️

여행 영어 앱이에요. **내 수준을 6가지 중에서 골라서** 공부해요.
**단어를 외우고**, **소리 내어 말하고**, **상대방 말을 알아듣는** 연습을 해요.

**▶ 바로 가기: https://gkes1211-hash.github.io/kang/english/travel/**
(휴대폰에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요)

## 이렇게 공부해요

| 화면 | 하는 일 |
| --- | --- |
| **오늘** | **▶ 오늘 공부 시작** 한 번이면 끝: 복습할 단어 + 새 단어 6개 + 따라 말하기 2개 + 듣기 2개 (약 5분). 🔥 연속 공부한 날을 세어 줘요 |
| **단계** | 8단계를 차례로 공부해요. 앞 단계를 50% 넘게 하면 다음 단계가 열려요 |
| **단어장** | 모든 단어와 외운 정도(🟠 배우는 중, 🟢 외움). 😵 자주 틀린 단어만 모아 연습 |
| **설정** | 말하기 속도(🐢 아주 천천히~보통), 목소리, 한글 발음 보기, 하루 새 단어 수, 기록 옮기기 |

### 수준 (설정이나 첫 화면에서 골라요)

| 수준 | 이런 말을 해요 |
| --- | --- |
| 🧸 유치원생 | "Water, please." 낱말 하나, 아주 짧은 말 |
| 🎒 초등 저학년 | "Can I have some water, please?" 짧고 쉬운 문장 |
| 📘 초등 고학년 | "Could you tell me where the bus stop is?" 묻고 답하기, 공손한 부탁 |
| 🏫 중학생 | "I booked a room for three nights, but…" 지난 일 설명, 문제 알리기 |
| 🎓 고등학생 | "My flight was cancelled. Could you rebook me?" 문제 해결, 흥정, 항의 |
| 🧑‍💼 성인 | "Could we get the check whenever you get a chance?" 원어민 표현, 관용어 |

수준마다 같은 여행 상황 8단계(인사 → 돈 → 공항 → 호텔 → 식당 → 쇼핑 → 교통 → 아플 때·곤란할 때)를 그 수준에 맞는 단어와 문장으로 공부해요.
수준 안에서는 앞 단계를 50% 넘게 하면 다음 단계가 열리고, 수준마다 기록이 따로 남아요.
모두 단어 608개, 말할 문장 315개, 듣기 304개, 역할극 회화 57개가 들어 있어요.
(🏫 중학생 수준부터는 문장에 한글 발음을 달지 않아요. 단어에는 계속 달아요.)

### 단계마다 하는 것

1. **📖 새 단어 배우기**: 그림, 영어, 한글 발음, 뜻을 보고 소리를 들어요. 바로 퀴즈로 확인해요.
2. **✏️ 단어 퀴즈**: 뜻 고르기, 영어 고르기, 듣고 뜻 고르기.
3. **🗣️ 따라 말하기**: 마이크에 말하면 ⭐ 점수를 주고, 틀린 낱말을 빨간색으로 보여 줘요.
4. **👂 듣고 알아듣기**: 여행지 사람들이 하는 말("For here or to go?")을 소리만 듣고 뜻을 골라요.
5. **💬 실전 회화 (역할극)**: 상대방(앱)이 말하면 내가 영어로 대답해요. 틀려도 "한 번 더!"로 다시 할 수 있고,
   익숙해지면 자막을 **영어+뜻 → 영어만 → 소리만**으로 바꿔 더 어렵게 연습해요.

### 잘 외워지는 이유

- **틀린 단어는 자주, 아는 단어는 드물게** 다시 나와요 (1일 → 2일 → 4일 → 8일 → 16일 → 30일 뒤 복습).
- 문제를 틀리면 같은 묶음 안에서 조금 뒤에 한 번 더 나와요.

## 꼭 알아 둘 것

- **말하기 채점**은 브라우저의 음성 인식을 써요. **크롬**(안드로이드·PC)이나 **사파리**(아이폰)에서 잘 돼요.
  처음에 마이크 사용을 **허용**해 주세요. 음성 인식은 인터넷이 연결되어 있어야 해요.
  음성 인식이 안 되는 브라우저에서는 소리 내어 읽고 스스로 확인하거나, 알맞은 말을 골라서 연습해요.
- 공부 기록은 **이 기기에만** 저장돼요. 다른 기기로 옮기려면 설정 › 💾 기록 옮기기에서 코드를 복사해 붙여 넣어요.
