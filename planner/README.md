# 우리 아이 공부 플래너 📒

아이와 부모님 둘이서 쓰는 학습 플래너예요. **엄마 앱**(`planner/`)과 **아이 앱**(`planner/kid/`) 두 가지가 있어요. 요일별로 반복되는 공부(수학 문제집, 영어 숙제, 한자, 역사·사회·과학책 읽기…)와 마감이 있는 숙제를 한곳에서 챙겨요.

## 화면

| 탭 | 하는 일 |
| --- | --- |
| **오늘** | 오늘 할 공부 체크, 달성률 링, 과목 필터·검색, 하루만 하는 할 일 추가, 메모, “이날만 빼기”, 마감 3일 안 숙제, ⭐ 부모님 확인 도장, 오늘 보고 복사/공유 |
| **주간** | 월~금 + 주말 카드, 주간 달성률, 숙제 마감 표시. 줄을 누르면 바로 체크 |
| **루틴** | 요일별 반복 공부 만들기 (여러 요일 한 번에, 평일/매일), 순서 바꾸기, 다른 요일로 복사, 과목 관리 |
| **숙제** | 마감일, 세부 할 일(1/3), 메모, D-day·밀린 숙제 표시, 완료 처리 |
| **기록** | 연속 다 끝낸 날, 최근 5주 달력(색 진하기 = 한 만큼, ★ = 부모님 확인), 과목별 꾸준함, 설정 |

## 아이 앱 (`kid/`)

아이 기기에서 `https://gkes1211-hash.github.io/kang/planner/kid/` 를 열고 홈 화면에 추가해요.

- 큰 체크 버튼으로 오늘 공부를 체크하고, 💬로 "어려웠어요" 같은 메모를 남겨요.
- 숙제는 세부 할 일을 하나씩 체크하고 “숙제 끝!”을 눌러요.
- 다 하면 노란 **🎉 엄마한테 다 했다고 알리기** 버튼 → 한마디 고르고 → **카톡으로 보내기 / 문자로 보내기 / 복사해서 보내기**.
- 루틴이나 숙제를 바꾸는 건 엄마 앱에서만 해요.

### 두 앱 잇기 (서버 없이 카톡으로)

| 방향 | 엄마가 할 일 |
| --- | --- |
| 엄마 → 아이 | 엄마 앱 오늘 탭 › 👧 아이 앱 › **📲 아이 기기로 보내기** → 카톡으로 아이에게 보내기 → 아이가 ⚙️ › 엄마 코드 넣기에 붙여 넣기. 처음 한 번, 그리고 루틴·숙제를 바꿀 때마다 (바뀐 게 있으면 “● 보낼 변경 있음”이 떠요) |
| 아이 → 엄마 | 아이가 보낸 카톡 글을 길게 눌러 복사 → 엄마 앱 › **📥 아이 소식 넣기**에 붙여 넣기 → 아이가 한 체크·메모·숙제가 엄마 앱에 들어와요 |

글 끝의 `HB1.…` 코드에 체크 내용이 들어 있어요. 코드는 카톡 대화방에만 남고 다른 곳으로 가지 않아요.

## 부모님 잠금

기록 탭 › 설정에서 4자리 비밀번호를 켜면 **아이 모드**가 돼요. 아이는 체크·메모·할 일 추가·숙제 추가를 할 수 있고,
루틴 바꾸기, 과목 관리, 숙제 지우기, 확인 도장, 백업 불러오기, 초기화는 비밀번호가 있어야 해요. 위쪽 배지를 눌러 모드를 바꿔요.

## 기록 저장

- 모든 기록은 **이 기기 브라우저 안에만** 저장돼요. 서버로 보내지 않아요.
- 다른 기기로 옮기려면 설정 › 백업 → 복사한 글을 새 기기의 “백업 불러오기”에 붙여 넣어요.
- 홈 화면에 추가하면 앱처럼 열리고, 인터넷 없이도 돼요.

처음에는 예시 시간표가 들어 있어요. 루틴 탭에서 우리 아이 교재와 요일에 맞게 바꿔 주세요.
