# 우리 아이 공부 플래너 📒

아이와 부모님 둘이서 쓰는 학습 플래너예요. 요일별로 반복되는 공부(수학 문제집, 영어 숙제, 한자, 역사·사회·과학책 읽기…)와 마감이 있는 숙제를 한곳에서 챙겨요.

## 화면

| 탭 | 하는 일 |
| --- | --- |
| **오늘** | 오늘 할 공부 체크, 달성률 링, 과목 필터·검색, 하루만 하는 할 일 추가, 메모, “이날만 빼기”, 마감 3일 안 숙제, ⭐ 부모님 확인 도장, 오늘 보고 복사/공유 |
| **주간** | 월~금 + 주말 카드, 주간 달성률, 숙제 마감 표시. 줄을 누르면 바로 체크 |
| **루틴** | 요일별 반복 공부 만들기 (여러 요일 한 번에, 평일/매일), 순서 바꾸기, 다른 요일로 복사, 과목 관리 |
| **숙제** | 마감일, 세부 할 일(1/3), 메모, D-day·밀린 숙제 표시, 완료 처리 |
| **기록** | 연속 다 끝낸 날, 최근 5주 달력(색 진하기 = 한 만큼, ★ = 부모님 확인), 과목별 꾸준함, 설정 |

## 부모님 잠금

기록 탭 › 설정에서 4자리 비밀번호를 켜면 **아이 모드**가 돼요. 아이는 체크·메모·할 일 추가·숙제 추가를 할 수 있고,
루틴 바꾸기, 과목 관리, 숙제 지우기, 확인 도장, 백업 불러오기, 초기화는 비밀번호가 있어야 해요. 위쪽 배지를 눌러 모드를 바꿔요.

## 기록 저장

- 모든 기록은 **이 기기 브라우저 안에만** 저장돼요. 서버로 보내지 않아요.
- 다른 기기로 옮기려면 설정 › 백업 → 복사한 글을 새 기기의 “백업 불러오기”에 붙여 넣어요.
- 홈 화면에 추가하면 앱처럼 열리고, 인터넷 없이도 돼요.
