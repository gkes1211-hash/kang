# 노래 연습장 🎤

마이크에 노래하면 **내가 부르는 음이 무슨 음인지, 높은지 낮은지** 바로 보여 주는 노래 연습 앱이에요.
음 맞추기, 목 풀기(발성 연습), 숨 길게 쓰기, 음역 재기, 녹음해서 듣기를 할 수 있어요.

**▶ 바로 가기: https://gkes1211-hash.github.io/kang/sing/**
(휴대폰에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요)

## 이렇게 연습해요

| 연습 | 하는 일 |
| --- | --- |
| **▶ 오늘의 연습** | 한 번이면 끝(약 5분): 💨 숨 고르고 길게 → 🪜 다섯 음 오르내리기 → 🎯 음 맞추기 5개 → 🎈 도미솔 화음 타기. 🔥 연속 연습한 날을 세어 줘요 |
| 🎚️ **음정 보기** | 부르는 음 이름(도레미 / C4)과 바늘로 "조금 높아요 ↓ / 낮아요 ↑ / 딱 맞아요"를 보여 주고, 음 높이를 선 그래프로 그려요 |
| 🎯 **음 맞추기** | 앱이 들려준 음을 똑같이 불러서 1초 동안 맞추면 성공. 빨리 맞출수록 점수가 높아요 (8문제, 100점) |
| 🪜 **발성 연습** | 다섯 음 오르내리기, 도미솔 화음, 도레미 음계, 옥타브 계단, 사이렌 미끄럼. 먼저 듣고 → 똑딱 두 번 → 따라 부르면 목표 막대 위에 내 음이 그려지고 % 로 채점해요. 한 번 끝날 때마다 반음씩 올라가요 |
| 💨 **길게 소리 내기** | 4초 들이마시고 2초 멈춘 뒤 '아~' 하고 길게. 몇 초 버텼는지, 음이 얼마나 흔들리지 않았는지 알려 줘요 |
| 📏 **내 음역 찾기** | 가장 낮은 음, 가장 높은 음을 불러서 내 음역을 재요. 그다음부터 연습 음을 내 음역에 맞춰 들려줘요 |
| 🎶 **반주 맞춰 부르기** | 가지고 있는 반주 파일(MR, mp3·m4a 등)을 넣어 두고 틀어 놓은 채 따라 불러요. 내가 부르는 음이 그래프로 보여요. 🅰️🅱️ **구간 반복**, 🐢 **느리게**(음 높이는 그대로), 반주 소리 크기, **반주랑 같이 녹음**, 📝 **가사** 붙여 넣어 보기. 반주와 가사는 이 기기에만 저장돼요 |
| 📼 **녹음** | 노래를 녹음하면 음 높이 그래프도 같이 남아요. 들을 때 그래프 위로 지금 위치가 움직여요. 💾 저장으로 파일로 받을 수 있어요 |
| 📊 **기록** | 연속 일, 연습한 시간, 최근 4주 달력, 최고 기록, 내 음역 |

### 설정

- **내 목소리**: 🐻 낮은 남자 · 🦁 높은 남자 · 🐬 낮은 여자 · 🐦 높은 여자 · 🐥 어린이, 또는 📏 직접 잰 음역
- **판정**: 😊 쉬움(±50센트) · 🙂 보통(±30센트) · 😤 어려움(±15센트)
- **음 이름**: 도레미 / CDE
- 한 옥타브 차이로 불러도 같은 음으로 쳐요 (예: 남자가 여자 음 높이 연습을 따라 부를 때)

## 꼭 알아 둘 것

- 처음에 마이크 사용을 **허용**해 주세요. 크롬(안드로이드·PC), 사파리(아이폰·아이패드)에서 잘 돼요.
- **🎧 이어폰을 끼면** 기준음이 마이크로 새지 않아 더 정확해요. (이어폰이 없으면 앱이 소리를 낼 동안은 마이크를 듣지 않아요)
- 마이크 소리는 **이 기기 안에서만** 음 높이를 계산하는 데 써요. 인터넷이 없어도 돼요.
- 연습 기록은 이 기기에만 저장돼요. 녹음은 💾 저장하지 않으면 앱을 닫을 때 지워져요.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html`, `style.css` | 화면 |
| `pitch.js` | 마이크 소리에서 음 높이 찾기(YIN 방식), 기준음 소리 내기, 음 이름 |
| `roll.js` | 음 높이 그림판 (목표 막대 + 내가 부른 선) |
| `karaoke.js` | 반주 맞춰 부르기: 반주 보관(IndexedDB), 구간 반복, 빠르기, 반주랑 같이 녹음, 가사 |
| `app.js` | 연습 흐름, 채점, 기록 저장, 녹음 |
| `manifest.webmanifest`, `sw.js`, `icons/` | 홈 화면 설치, 인터넷 없이 열기 |
