# 벽 통과하기 🧱🙆

**▶ 바로 하기: https://gkes1211-hash.github.io/kang/pe/byeok/**  (GitHub Pages가 켜져 있어야 해요. 켜는 법은 [맨 위 README](../../README.md) 참고)

벽이 다가와요! 벽에 뚫린 **구멍 모양대로 몸을 맞추면** 통과하는 몸놀이 게임이에요.
노트북·태블릿 카메라로 내 몸 뼈대를 찾아서, 팔·다리 각도가 구멍 모양과 맞는지 봐요.

## 놀이 방법

1. 혼자 / 둘이서, 난이도를 고르고 **시작!**을 눌러요. 카메라 앞에 몸이 보이게 서요.
2. "3, 2, 1, 시작!" 뒤에 멀리서 벽이 다가와요. 이번 자세 이름은 **말하지 않고 화면에만** 보여 줘요 (가운데 큰 글자, 아래 이름표).
3. 벽이 내 앞에 올 때까지 구멍 모양대로 몸을 맞춰요. 내 몸 뼈대에서 **맞은 팔·다리는 초록, 틀린 곳은 빨강**으로 보여요.
4. 벽이 닿는 순간 자세가 맞으면 **통과! 🎉** (아주 잘 맞으면 **완벽! ✨** 보너스), 틀리면 **꽝! 💥** 하고 목숨(❤️)이 하나 줄어요.
5. 목숨 3개를 다 쓰면 끝! 연속으로 통과하면 점수가 더 올라가요.

- 통과할수록 벽이 **점점 빨리** 오고, 3개 통과할 때마다 **더 어려운 자세**가 섞여 나와요.
- 통과하는 구멍은 언제나 화면 가운데에 나와요. 카메라 화면이 내 몸에 맞춰 움직여서, 숙이거나 자리를 옮기지 않고 자세만 맞추면 돼요.
- 게임 중에 화면 밖으로 나가면 벽이 멈추고 기다려 줘요.
- 잔잔하고 두근두근한 **배경음악**이 깔려요. 벽이 가까이 오면 박자가 빨라지고, 통과할수록 조금씩 빨라져요. 첫 화면 설정이나 게임 중 🎵 버튼으로 끌 수 있어요.

## 둘이서 👫

- **1P는 화면 왼쪽, 2P는 오른쪽**에 서요. 벽에 구멍이 두 개(1P 주황, 2P 파랑) 뚫려 있어요.
- **두 사람 모두** 자세를 맞춰야 통과해요! 한 명이라도 틀리면 "꽝! 💥 2P"처럼 누가 틀렸는지 알려 줘요. 목숨과 점수는 같이 써요 (통과할 때마다 둘이서 보너스 +50).
- 벽은 세 가지가 섞여 나와요.
  - **둘이 같이**: 커다란 하트 💞, 손잡고 만세 🤝, 다리 만들기 🌉, 한 마리 새 🕊️, 파도 타기 🌊, 쌍둥이 별 🌟, 대문 ⛩️, 하트 다리 💘, 커플 댄스 💃
  - **똑같이 👯**: 둘이 같은 자세
  - **거울처럼 🪞**: 2P는 1P를 거울에 비춘 자세

## 난이도

| | 🐣 쉬움 | 🐰 보통 | 🦅 어려움 |
| --- | --- | --- | --- |
| 보는 곳 | 팔만 | 팔 + 다리 | 팔 + 다리 |
| 자세 | 팔 자세 21가지 (만세·활쏘기·닭 날개·허수아비·문어 춤·횃불…) | + 다리·몸통 자세 12가지 (홍학·개구리·나무·주전자·피사의 사탑·초승달…) | + 섞은 자세 10가지 (서핑·축구 슛·로켓·닌자·꽃게·태권도…) |
| 봐주는 정도 | 많이 (±42°) | 보통 (±33°) | 조금 (±27°) |
| 벽 속도 | 천천히 (7초 → 4.5초) | 보통 (5.5초 → 3.2초) | 빠르게 (4.5초 → 2.5초) |
| 길잡이 | 내 자리에 맞출 모양을 노란 점선으로 | 노란 점선 | 없음 |
| 깜짝 변신 | 없음 | 없음 | 벽이 다가오다가 **구멍 모양이 바뀌어요! 🔄** |

다리·몸통 자세는 발까지 화면에 보일 때만 나와요. 다리가 안 보이면 팔 자세만 나와요.

## 어떻게 맞는지 재나요?

- 위팔·아래팔·허벅지·종아리 하나하나와 **몸통 기울기**를 "아래로 0°, 옆으로 90°, 위로 180°" 같은 **각도**로 바꿔서 구멍 자세의 각도와 비교해요. 그래서 키가 크든 작든, 카메라에서 멀든 가깝든 같은 기준이에요.
- 벽 구멍은 화면 가운데(둘이서는 왼쪽 반·오른쪽 반 가운데)에 같은 크기로 뚫고, 카메라 화면을 옮기고 키워서 내 몸을 구멍에 겹쳐 보여 줘요. 왼쪽·오른쪽은 화면(거울)에 보이는 대로예요.
- 둘이서는 화면을 왼쪽·오른쪽 반으로 나눠 한 사람씩 따로 찾아요.
- 벽이 닿기 직전 잠깐 동안 가장 잘 맞았던 자세로 판정해서, 마지막 순간 살짝 흔들려도 봐줘요.
- 자세는 `poses.js`에 각도 숫자로 적혀 있어서 새 자세를 쉽게 더할 수 있어요 (둘이서 짝 자세는 `PAIR_POSES`).

## 몸 인식·개인정보

- 옆 폴더 [무궁화 꽃이 피었습니다](../mugunghwa/)와 같은 몸 인식(구글 MediaPipe Pose Landmarker lite)을 **같이 써요** (`../mugunghwa/pose.js`, `../mugunghwa/vendor/`). 그래서 두 폴더를 같이 올려야 해요.
- 카메라 영상은 **이 기기 안에서만** 몸 뼈대를 찾는 데 쓰고, 저장하지도 어디로 보내지도 않아요. 페이지의 보안 규칙(Content-Security-Policy)이 다른 서버와의 연결을 모두 막아요.
- 목소리("통과!", "꽝!" 같은 짧은 말)는 기기에 설치된 한국어 목소리만 써요. 없으면 효과음만 나요.
- 배경음악은 파일 없이 기기 안에서 바로 만들어요.

## 열기·설치

카메라는 보안 주소(`https://`)나 `localhost`에서만 켜져요. 이 저장소를 GitHub Pages처럼 `https://`로 올리고 `…/byeok/`를 열면 돼요.
홈 화면에 추가하면 다음부터는 인터넷 없이도 열려요.

- 주소 끝에 `?demo`를 붙이면 카메라 없이 **가짜 몸**이 혼자 자세를 맞추는 연습 화면이 나와요 (화면 확인용).
