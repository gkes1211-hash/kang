# 무궁화 꽃이 피었습니다 🌺

노트북이나 태블릿 카메라가 술래가 되는 아이들 몸놀이 게임이에요.

## 놀이 방법

1. 카메라 앞에 몸이 보이게 서요. 둘이서 할 때는 **1P는 화면 왼쪽, 2P는 화면 오른쪽**에 서요.
2. 술래가 사람을 찾으면 "찾았다!"라고 말하고, 화면에 내 몸 뼈대(어깨·팔·다리 선)가 그려져요. 모두 찾을 때까지 게임은 시작하지 않아요.
3. 3초 동안 가만히 서 있어요. 이때 술래가 "가만히 있어도 생기는 떨림"을 재요.
4. 술래가 "무궁화 꽃이 피었습니다~"를 부르는 동안 **제자리에서 팔 흔들기, 제자리 달리기**를 해요. 팔·다리를 크게 움직일수록 내 캐릭터가 술래 쪽으로 빨리 가요.
5. 술래가 **"얼음!"** 하고 돌아보면 딱 멈춰요. 이때 움직이면 걸려서 뒤로 가요. (멈추는 데 걸리는 시간은 조금 봐줘요)
6. 술래에게 먼저 도착하면 이겨요! 게임 중에 화면 밖으로 나가면 "안 보여요!"가 뜨고, 돌아올 때까지 앞으로 가지 않아요.

## 화면

- **왼쪽**: 내 모습(카메라)과 몸 뼈대, 그 아래 **움직임 게이지**. 노래할 때는 게이지가 세로 줄을 넘어야 앞으로 가요("달려요! 🏃"). 얼음 때는 세로 줄을 넘으면 걸려요.
- **오른쪽**: 해·구름·언덕·꽃밭·나비가 있는 들판. 토끼(1P)와 곰(2P)이 **출발**에서 **🏁 골인**까지 왼쪽에서 오른쪽으로 달려요. 골인 지점의 무궁화 나무 아래에 술래가 있어요.
- 세로로 세운 태블릿에서는 카메라가 위, 들판이 아래로 가요.

## 설정

| 설정 | 고를 수 있는 것 |
| --- | --- |
| 누가 해요? | 혼자 / 둘이서 (왼쪽 1P, 오른쪽 2P) |
| 술래 눈치 | 너그러움 (조금 움직여도 봐줌) · 보통 · 매의 눈 (아주 살짝만 움직여도 걸림) |
| 술래 목소리 | 켜기 / 끄기 (끄면 화면 글자와 "삐" 소리로 알려 줌) |

고른 설정은 이 기기에 저장되어 다음에도 그대로 나와요.

## 몸 인식

- 구글의 무료 몸 인식 모델 [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) (lite)를 써요. 엔진과 모델 파일은 이 폴더의 `vendor/`에 들어 있어서 **기기 안에서만** 돌아가요.
- 둘이서 할 때는 화면을 왼쪽·오른쪽 반으로 나눠 한 사람씩 따로 찾아요. 그래서 한 사람이 크게 움직여도 옆 사람이 억울하게 걸리지 않아요.
- 움직임은 "몸통 길이에 비해 팔꿈치·손목·무릎·발목이 얼마나 빨리 움직였나"로 재요. 그래서 카메라에서 멀리 서도, 가까이 서도 같은 기준이에요.
- 처음 열 때 엔진과 모델(약 20MB)을 한 번 받아요. 설치하면 그다음부터는 인터넷 없이도 돼요.
- 몸 인식을 켤 수 없는 오래된 기기에서는 예전 방식(화면에서 바뀐 부분 재기)으로 자동으로 바뀌어요. 이때는 "팔을 흔들어 주세요"로 참가해요.
- 주소 끝에 `?debug`를 붙이면 움직임 숫자를 화면에 보여 줘요. 술래 눈치를 맞출 때 써요.

## 개인정보

- 카메라 영상은 **이 기기 안에서만** 몸 뼈대를 찾고 "얼마나 움직였는지"만 계산해요. 저장하지도, 어디로 보내지도 않아요.
- 페이지에 보안 규칙(Content-Security-Policy)을 걸어 두어서, 이 앱은 자기 자신 말고 다른 서버와는 연결할 수 없어요. (MediaPipe 안에는 구글로 사용 통계를 보내는 기능이 있지만 기본으로 꺼져 있고, 켜지더라도 이 보안 규칙에 막혀요.)
- 술래 목소리도 기기 안에 설치된 한국어 목소리만 써요. 기기에 한국어 목소리가 없으면 소리 대신 "삐" 소리가 나요.

## 홈 화면에 설치하기

카메라는 보안 주소(`https://`)나 `localhost`에서만 켜져요. 이 폴더를 `https://` 주소로 올리면 (예: GitHub Pages) 아래처럼 설치할 수 있어요.

- **안드로이드·크롬**: 주소창 메뉴 → "홈 화면에 추가" 또는 "앱 설치"
- **아이패드·아이폰 사파리**: 공유 버튼 → "홈 화면에 추가"
- **윈도우·맥 크롬/엣지**: 주소창 오른쪽의 설치 아이콘

한 번 설치하면 인터넷이 없어도 열려요.
