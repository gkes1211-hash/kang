# 체력왕 운동 카운터 💪

카메라가 운동 횟수를 세어 주는 체육 게임이에요. **제대로 한 것만** 세요!

## 운동

| 운동 | 이렇게 하면 1번 | 30초 목표 | 60초 목표 |
| --- | --- | --- | --- |
| 🏋️ 스쿼트 | 허벅지가 바닥과 나란할 만큼 앉았다가 일어나기 | 12개 | 25개 |
| 🙆 팔 벌려 뛰기 | 팔은 머리 위로·다리는 옆으로 벌렸다가 다시 모으기 | 20개 | 40개 |
| 🏃 제자리 무릎 들기 | 무릎을 허리 높이까지 들기 (한쪽마다 1번) | 40번 | 80번 |

- 덜 하면 세지 않고 "조금 더 깊이 앉아요!", "팔을 머리 위까지!", "무릎을 허리 높이까지!"처럼 알려 줘요.
- 아래 게이지가 지금 동작을 얼마나 했는지 보여 줘요. 초록이 되면 한 번으로 셀 준비가 된 거예요.
- 목표를 넘으면 **🎖️ 목표 달성! 체력왕!** 도장, 운동·시간마다 최고 기록을 이 기기에 저장해요.
- **둘이서**: 1P는 화면 왼쪽, 2P는 오른쪽. 같은 시간 동안 누가 더 많이 하나 대결!

## 어떻게 세나요?

- 몸 뼈대(어깨·엉덩이·무릎·손목·발목)를 찾아 **몸통 길이 단위**로 재요. 멀리 서든 가까이 서든 같은 기준이에요.
- 정면 카메라에서는 무릎이 굽은 각도가 잘 안 보여서(허벅지가 카메라 쪽을 향함), 스쿼트·무릎 들기는 **무릎이 엉덩이 높이에 얼마나 가까워졌나**로 재요.
- 팔 벌려 뛰기는 두 손목이 어깨 위로 충분히 올라갔는지, 발이 보이면 두 발이 충분히 벌어졌는지도 봐요.
- 주소 끝에 `?demo`를 붙이면 카메라 없이 가짜 몸이 운동하는 연습 화면이 나와요.

## 개인정보

카메라 영상은 이 기기 안에서만 써요. 저장하지도, 어디로 보내지도 않아요.
몸 인식 엔진은 [무궁화](../mugunghwa/) 폴더의 것을, 카메라·소리 도우미는 [`common/`](../common/)의 것을 같이 써요.
