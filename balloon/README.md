# 풍선 터트리기 🎈💥

카메라 앞에서 손을 휘저어 풍선을 터트리는 게임이에요.

## 놀이 방법

1. **시작!** 을 누르고 카메라 사용을 허락해요.
2. 화면에 내 모습이 거울처럼 나오고, 손에 빛나는 점이 표시돼요 (두 손 모두 인식).
3. 아래에서 올라오는 풍선에 손을 대면 **펑!** 터지고 점수가 올라가요.
4. 위에서 떨어지는 **💣 폭탄**에 손이 닿으면 **-5점**! 화면이 흔들리고 콤보도 끊겨요.
5. 시간이 지날수록 풍선과 폭탄이 더 빨리, 더 자주 나와요.

| 물건 | 점수 |
| --- | --- |
| 🎈 풍선 | +1 |
| 🎈 작은 풍선 (더 빠름) | +2 |
| 🌟 금색 풍선 (드물고 빠름) | +5 |
| 💣 폭탄 | -5 (0점 밑으로는 안 내려가요) |
| 🔥 콤보 5 이상 (1.5초 안에 연달아) | 풍선마다 +1 추가 |

## 난이도

손바닥 가운데에 **✋ 동그라미**가 생기고, 이 동그라미가 풍선에 닿아야 터져요 (손가락 끝이 스치는 건 안 쳐요).

| 난이도 | 손 동그라미 | 속도 | 폭탄 |
| --- | --- | --- | --- |
| 😊 쉬움 | 보통 풍선보다 조금 큼 | 느림 | 적음 |
| 🙂 보통 | 보통 풍선만 함 | 보통 | 보통 |
| 🔥 어려움 | 작은 풍선만 함 | 빠름, 작은 풍선 많음 | 많음 |

게임 시간은 30 / 60 / 90초 중에 골라요. 최고 점수는 난이도마다 따로 이 기기에 저장돼요.

## 손 인식

- 구글 MediaPipe **Hand Landmarker** 모델(`vendor/hand_landmarker.task`)을 기기 안에서 돌려요.
- 인식 엔진(`vision_bundle.mjs`, wasm)은 옆 폴더 `../mugunghwa/vendor/` 것을 같이 써요. 그래서 이 저장소를 통째로 올려야 동작해요.
- 손목과 네 손가락 뿌리의 가운데(손바닥 가운데)가 "닿는 곳"이에요. 손을 빨리 움직여도 지나간 길에 있던 풍선은 터져요.
- 페이지 보안 규칙(CSP)이 바깥 연결을 모두 막아서 카메라 영상은 어디로도 나가지 않아요.

## 실행

카메라는 `https` 나 `localhost` 에서만 켜져요. 저장소 폴더에서:

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000/balloon/` 을 열어요. (GitHub Pages로 올려도 돼요.)

## 파일 하나로 실행 (서버 없이 더블클릭)

```bash
python3 balloon/build_single.py
```

`dist/풍선터트리기.html` (약 30MB) 이 만들어져요. 엔진과 손 모델이 모두 들어 있어서 이 파일만 있으면 돼요.
크롬이나 엣지에서 더블클릭해 열고, 카메라를 허락하면 바로 시작해요.

## 바탕화면 풍선 아이콘 (Windows)

`build_single.py` 는 `dist/풍선터트리기.zip` 도 만들어요. 압축을 풀고 `바로가기만들기.bat` 을 더블클릭하면:

- 게임 파일과 아이콘을 `%LOCALAPPDATA%\BalloonGame` 에 복사하고
- 바탕화면에 🎈 풍선 아이콘이 달린 **풍선 터트리기** 바로가기를 만들어요.

아이콘은 `python3 balloon/make_icon.py` 로 다시 그릴 수 있어요 (`icon.png`, `balloon.ico`).
