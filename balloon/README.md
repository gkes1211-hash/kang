# 풍선 터트리기 🎈💥

카메라 앞에서 손을 휘저어 풍선을 터트리는 게임이에요.

## 놀이 방법

1. **시작!** 을 누르고 카메라 사용을 허락해요.
2. 화면에 내 모습이 거울처럼 나오고, 손에 빛나는 점이 표시돼요 (두 손 모두 인식).
3. 아래에서 올라오는 풍선에 손을 대면 **펑!** 터지고 점수가 올라가요. 작은 풍선일수록 점수가 커요.
4. 위에서 떨어지는 **💣 폭탄**에 손이 닿으면 점수가 깎여요 (작은 폭탄 -1 ~ 큰 폭탄 -5)! 화면이 흔들리고 콤보도 끊겨요.
5. 시간이 지날수록 풍선과 폭탄이 더 빨리, 더 자주 나와요.

| 물건 | 점수 |
| --- | --- |
| 🎈 풍선 (크기 5단계, 풍선에 점수가 써 있어요) | 가장 큰 +1 · +2 · +3 · +4 · 가장 작은 +5 |
| 🌟 금색 풍선 (드물고 빠름) | +10 |
| 💣 폭탄 (크기 5단계, 폭탄에 숫자가 써 있어요) | 가장 작은 -1 · -2 · -3 · -4 · 가장 큰 -5 (0점 밑으로는 안 내려가요) |
| 🔥 콤보 5 이상 (1.5초 안에 연달아) | 풍선마다 +1 추가 |

## 혼자 / 둘이서 대결

- **혼자**: 화면 가운데 구역에서만 풍선과 폭탄이 나오고, 손도 그 구역 안에 있어야 터트릴 수 있어요. 구역 밖에 있는 손은 회색으로 보여요.
- **둘이서 대결**: 화면을 반으로 나눠 왼쪽이 **1P**(주황), 오른쪽이 **2P**(파랑)예요. 난이도는 같고, 풍선과 폭탄은 양쪽에 따로따로 나와요. 각자 자기 쪽 풍선만 터트릴 수 있고, 시간이 끝났을 때 점수가 높은 쪽이 이겨요. 손은 넷까지 인식해요.

## 화면

카메라에 비친 내 모습이 화면 가득 나오고, 그 위에 웃는 해님·구름, 옅은 무지개, 아래쪽 꽃 풀밭이 장식으로 깔려요.
손은 뼈대(손가락 마디)와 손바닥이 굵은 선으로 그려져요. 그려진 손 모양 그대로가 풍선을 터트리는 곳이에요.

## 배경음악

게임 중에는 직접 만든 신나는 8마디 멜로디가 되풀이돼요 (파일 없이 브라우저가 소리를 만들어요). 마지막 10초에는 음악이 빨라지고, 끝나면 짧은 팡파르가 울려요.
첫 화면의 **배경음악 켜기/끄기** 나 게임 중 오른쪽 위 🎵 버튼으로 끌 수 있어요.

## 난이도

**손 전체**(손가락 마디마디와 손바닥)가 풍선에 닿으면 터져요. 난이도에 따라 손 둘레를 얼마나 넉넉히 쳐 주는지가 달라요.

| 난이도 | 손 둘레 여유 | 속도 | 폭탄 |
| --- | --- | --- | --- |
| 😊 쉬움 | 큼 | 느림, 큰 풍선 많음 | 적음 |
| 🙂 보통 | 보통 | 보통 | 보통 |
| 🔥 어려움 | 거의 없음 (정확히 닿아야 함) | 빠름, 작은(점수 큰) 풍선 많음 | 많음 |

게임 시간은 30 / 60 / 90초 중에 골라요. 최고 점수는 난이도마다 따로 이 기기에 저장돼요.

## 손 인식

- 구글 MediaPipe **Hand Landmarker** 모델(`vendor/hand_landmarker.task`)을 기기 안에서 돌려요.
- 인식 엔진(`vision_bundle.mjs`, wasm)은 옆 폴더 `../mugunghwa/vendor/` 것을 같이 써요. 그래서 이 저장소를 통째로 올려야 동작해요.
- 손가락 뼈대와 손바닥 전체가 "닿는 곳"이에요. 손을 빨리 움직여도 손가락 끝과 손바닥이 지나간 길에 있던 풍선은 터져요.
- 페이지 보안 규칙(CSP)이 바깥 연결을 모두 막아서 카메라 영상은 어디로도 나가지 않아요.

## 실행

카메라는 `https` 나 `localhost` 에서만 켜져요. 저장소 폴더에서:

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000/balloon/` 을 열어요. (GitHub Pages로 올려도 돼요.)

## 파일 하나로 실행 (서버 없이 더블클릭)

```bash
python3 balloon/build_single.py
```

`dist/풍선터트리기.html` (약 30MB) 이 만들어져요. 엔진과 손 모델이 모두 들어 있어서 이 파일만 있으면 돼요.
크롬이나 엣지에서 더블클릭해 열고, 카메라를 허락하면 바로 시작해요.

## 바탕화면 풍선 아이콘 (Windows)

`build_single.py` 는 `dist/풍선터트리기.zip` 도 만들어요. 압축을 풀고 `바로가기만들기.bat` 을 더블클릭하면:

- 게임 파일과 아이콘을 `%LOCALAPPDATA%\BalloonGame` 에 복사하고
- 바탕화면에 🎈 풍선 아이콘이 달린 **풍선 터트리기** 바로가기를 만들어요.

아이콘은 `python3 balloon/make_icon.py` 로 다시 그릴 수 있어요 (`icon.png`, `balloon.ico`).

## 자동 업데이트

`dist/풍선터트리기.html` 은 켜질 때 GitHub(`claude/elegant-allen-9dx5iv` 브랜치)에서 `balloon/index.html`, `style.css`, `game.js` 의 최신판을 받아서 써요.
그래서 이 세 파일을 고쳐서 올리면, 이미 설치한 바로가기도 다음에 켤 때 새 버전으로 열려요 (GitHub 캐시 때문에 최대 5분쯤 늦을 수 있어요).
인터넷이 없거나 4초 안에 못 받으면 파일 안에 든 판으로 그냥 시작해요. 손 인식 엔진과 모델은 늘 파일 안의 것을 써요.
브랜치 이름이 바뀌면 `build_single.py` 의 `UPDATE_BASE` 를 고쳐서 다시 만들어요.
