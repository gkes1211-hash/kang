# 제기차기 🪶

화면 속 제기를 **발이나 무릎**으로 차올리는 전통 놀이 게임이에요.

## 놀이 방법

1. 발까지 화면에 보이게 뒤로 서요. **멀리 서도 화면이 나를 크게 키워 보여 줘요** (서 있는 몸이 화면 세로의 85%쯤). 발과 무릎에 노란 동그라미가 보이면 준비 끝!
   - 태블릿·노트북을 의자나 바닥 가까이 **낮게** 두면 가까이 서도 발까지 보여요.
   - 뒤로 갈 자리가 없으면 **어디로 차요? → ✋ 손·무릎도**를 골라요. 가까이 서서 손바닥이나 무릎으로 제기를 쳐 올려요.
2. "3, 2, 1, 차요!" 뒤에 위에서 제기가 떨어져요.
3. 떨어지는 제기에 발이나 무릎을 대서 차올려요. 차면 화면 위쪽까지 다시 올라가요.
4. 바닥(발 아래)까지 떨어지면 연속 기록이 0으로 돌아가요.

- **혼자**: 세 번 떨어뜨리면 끝. **최고 연속 기록**을 난이도마다 저장해요. 10번 넘게 이어 차면 "제기차기 달인!"
- **둘이서**: 1P는 화면 왼쪽, 2P는 오른쪽에서 각자 제기를 차요. 60초 동안 **모두 찬 횟수**가 많은 쪽이 이겨요. 떨어뜨려도 새 제기가 다시 떨어져요.

## 난이도

| | 🐣 쉬움 | 🐰 보통 | 🦅 어려움 |
| --- | --- | --- | --- |
| 오르내리는 빠르기 | 보통 | **빠르게** | **아주 빠르게** |
| 차는 법 | 발·무릎을 위로 차올려야 해요 | 더 세게 차올려야 해요 | 아주 세게, 더 가까이에서 |
| 올라가는 높이 | 늘 비슷하게 | 조금씩 달라요 | 매번 많이 달라요 |
| 날아가는 방향 | 옆으로 조금 | 차는 모양 따라 + 랜덤 | 차는 모양 따라 + 많이 랜덤 |

**차는 모양에 따라 날아가는 방향**: 제기의 오른쪽을 차면 왼쪽으로, 왼쪽을 차면 오른쪽으로 날아가요. 발을 옆으로 쓸어 차면 그쪽으로 더 날아가요. 무릎으로 차면 거의 위로, 발로 차면 비스듬히 날아가요. 여기에 난이도만큼 랜덤이 더해져요.

> 난이도를 한 단계씩 어렵게 바꿨어요 (예전 어려움 = 지금 쉬움). 그래서 최고 기록도 새로 세요.

## 만든 방법

- 몸 뼈대에서 발목·발끝·뒤꿈치·무릎을 찾아, 제기와의 거리와 발이 움직이는 방향·빠르기로 "찼다"를 판단해요.
- 카메라 화면을 내 몸에 맞춰 옮기고 키운 다음, 그 위에서 제기를 떨어뜨리고 차기를 판단해요. 그래서 멀리 서도 제기와 내 몸이 크게 보여요. (이미 가까이 서 있으면 키우지 않아요)
- 제기는 중력을 받아 떨어지고, 차면 화면 위쪽까지 올라가게 다시 튀어 올라요. 종이 술은 바람을 받는 쪽으로 날려요.
- 주소 끝에 `?demo`를 붙이면 카메라 없이 가짜 몸이 제기를 차는 연습 화면이 나와요.

## 개인정보

카메라 영상은 이 기기 안에서만 써요. 저장하지도, 어디로 보내지도 않아요.
