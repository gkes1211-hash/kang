# 제기차기 🪶

화면 속 제기를 **발이나 무릎**으로 차올리는 전통 놀이 게임이에요.

## 놀이 방법

1. 발까지 화면에 보이게 조금 뒤로 서요. 발과 무릎에 노란 동그라미가 보이면 준비 끝!
2. "3, 2, 1, 차요!" 뒤에 위에서 제기가 떨어져요.
3. 떨어지는 제기에 발이나 무릎을 대서 차올려요. 차면 화면 위쪽까지 다시 올라가요.
4. 바닥(발 아래)까지 떨어지면 연속 기록이 0으로 돌아가요.

- **혼자**: 세 번 떨어뜨리면 끝. **최고 연속 기록**을 난이도마다 저장해요. 10번 넘게 이어 차면 "제기차기 달인!"
- **둘이서**: 1P는 화면 왼쪽, 2P는 오른쪽에서 각자 제기를 차요. 60초 동안 **모두 찬 횟수**가 많은 쪽이 이겨요. 떨어뜨려도 새 제기가 다시 떨어져요.

## 난이도

| | 🐣 쉬움 | 🐰 보통 | 🦅 어려움 |
| --- | --- | --- | --- |
| 떨어지는 빠르기 | 천천히 | 보통 | 빠르게 |
| 차는 법 | 발·무릎에 **닿기만** 하면 OK | 발·무릎을 **위로 차올려야** 해요 | 위로 차올려야 하고, 닿는 거리가 더 짧아요 |
| 옆으로 튀기 | 조금 | 보통 | 많이 |

## 만든 방법

- 몸 뼈대에서 발목·발끝·뒤꿈치·무릎을 찾아, 제기와의 거리와 발이 움직이는 방향·빠르기로 "찼다"를 판단해요.
- 제기는 중력을 받아 떨어지고, 차면 화면 위쪽까지 올라가게 다시 튀어 올라요. 종이 술은 바람을 받는 쪽으로 날려요.
- 주소 끝에 `?demo`를 붙이면 카메라 없이 가짜 몸이 제기를 차는 연습 화면이 나와요.

## 개인정보

카메라 영상은 이 기기 안에서만 써요. 저장하지도, 어디로 보내지도 않아요.
몸 인식 엔진은 [무궁화](../mugunghwa/) 폴더의 것을, 카메라·소리 도우미는 [`common/`](../common/)의 것을 같이 써요.
