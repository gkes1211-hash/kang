# 픽셀 마법사 연구소 🪄

> **작은 픽셀에 마법을 걸어봐!**
> 초등학생이 코딩 블록으로 픽셀 그림을 그리고, 움직이는 애니메이션까지 만드는 교육용 웹앱

- 대상: 초등 1~6학년 (주 대상 2~4학년)
- 회원가입·서버·API 키 없이 브라우저만 있으면 실행
- 정적 웹 호스팅(GitHub Pages, Netlify, 학교 웹서버 등)이나 내 컴퓨터에서 바로 사용

---

## 1. 바로 써 보기 (설치 없이)

이미 만들어진 배포 파일이 `dist/` 폴더에 들어 있습니다.

- **웹 서버에 올리기**: `dist/` 폴더 안의 파일을 통째로 웹 서버(예: GitHub Pages, Netlify, 학교 홈페이지 공간)에 올리면 됩니다. 하위 경로에서도 동작합니다.
- **내 컴퓨터에서 열기**: 브라우저 보안 때문에 `index.html` 을 더블클릭하면 열리지 않을 수 있습니다. 아래 "개발 환경에서 실행"의 `npm run preview` 를 쓰거나, `dist/` 폴더에서 간단한 웹 서버를 실행하세요.

```bash
npx serve dist
```

권장 브라우저: 크롬, 엣지, 웨일 (최신 버전)

## 2. 개발 환경에서 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 터미널에 표시된 주소(보통 http://localhost:5173)를 엽니다.

### 배포용 빌드

```bash
npm run build
```

`dist/` 폴더에 정적 파일이 만들어집니다. 만든 결과를 확인하려면:

```bash
npm run preview
```

### 테스트

```bash
npm test
```

실행 엔진·반복문·중첩 반복·도화지 밖 이동·안전 제한·블록 편집·**12개 미션 모범 답안 검증**·그림→코드 자동 변환·GIF 인코더를 검사합니다 (36개 테스트).

```bash
npm run build && npm run e2e
```

실제 크롬(Chromium) 브라우저로 앱을 조작하는 종합 검사입니다 (Playwright 필요). 12개 미션을 브라우저에서 직접 실행해 성공 판정을 확인하고, 단계 실행·일시정지·드래그·오류 표시·저장/불러오기·새로고침 유지·PNG/GIF 다운로드·애니메이션 재생·1366×768 / 1280×720 / 1280×600 화면에서 스크롤 없음 등을 검사합니다. 스크린샷은 `e2e/shots/` 에 저장됩니다.

## 바탕화면 아이콘으로 실행하기 (마법사 모자 아이콘)

**방법 1. 윈도우 바로가기 (지금 바로)**
`desktop-shortcut/` 폴더를 컴퓨터에 저장하고 `make-shortcut.bat` 을 두 번 누르면, 바탕화면에 마법사 모자 아이콘의 "픽셀 마법사 연구소" 바로가기가 생깁니다. 누르면 claude.ai 웹페이지 버전이 열립니다. ("Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]) 자세한 내용은 폴더 안 `읽어주세요.txt` 를 보세요.

**방법 2. 앱으로 설치 (dist 를 https 주소에 올린 경우)**
`dist/` 를 GitHub Pages·학교 서버 등 `https://` 주소에 올리고 크롬·엣지로 열면, 주소창 오른쪽의 **앱 설치** 버튼으로 설치할 수 있습니다. 바탕화면·시작 메뉴에 모자 아이콘이 생기고, 한 번 연 뒤에는 인터넷 없이도 열립니다. (태블릿: "홈 화면에 추가")

아이콘 그림은 `scripts/make-icons.py` 로 만들며 `public/icons/` 에 있습니다.

## 3. 세 가지 모드

### A. 마법 따라 그리기 (코딩 미션)
목표 그림을 보고 명령 블록을 조립해 마법 펜으로 똑같이 그리는 학습 모드입니다.

| 단계 | 미션 | 핵심 학습 | 난이도 |
|---|---|---|---|
| 1 | 첫 번째 마법 점 | 색칠 명령 | 쉬움 |
| 2 | 반짝이는 가로줄 | 이동과 순서 | 쉬움 |
| 3 | 알록달록 계단 | 방향 명령 | 쉬움 |
| 4 | 네모난 마법 창문 | 이동과 패턴 | 쉬움 |
| 5 | 하트 만들기 | 좌표와 색칠 | 쉬움 |
| 6 | 반복되는 무지개 | 반복문 | 보통 |
| 7 | 마법사의 꽃 | 반복과 패턴 | 보통 |
| 8 | 별빛 장식 | 효율적인 명령 | 보통 |
| 9 | 귀여운 버섯 | 색 변경과 반복 | 보통 |
| 10 | 마법사의 시험 | 종합 미션 | 보통 |
| 11 | 체크무늬 마법 바닥 | 반복 속 반복(중첩) | 도전 |
| 12 | 고장 난 웃음 주문 | 디버깅 | 도전 |

- 미션마다 **개념 카드**, **3단계 힌트**, **목표 겹쳐 보기**, **모범 답안(선생님용 "정답 코드")** 제공
- 성공 판정은 **그림 비교**로 합니다. 코드 순서가 모범 답안과 달라도 결과가 같으면 성공입니다.
- 별: 완성 1개 + 블록을 아껴 쓰면 보너스 별 (모범 답안 블록 수 이하 → 3개, 1.5배 이하 → 2개)
- 실패해도 점수를 깎지 않고, 목표와 다른 칸에 **빗금 + 점선 테두리 + ✕** 를 표시합니다 (색만으로 구분하지 않음)
- 앞 미션을 끝내면 다음 미션이 열립니다. 미션 지도에서 **선생님 모드: 모든 미션 열기**를 켜면 바로 원하는 미션으로 갈 수 있습니다.
- 작성 중인 코드는 미션별로 자동 저장됩니다.

### B. 자유 픽셀 공방 (창작)
- 8×8 / 10×10 / 16×16 도화지, 12색 팔레트
- 기본은 **명령 블록으로 그리기**. 보조 기능인 **그리기 도우미**를 켜면 도화지 칸을 누를 때 "그 칸까지 가서 칠하는 블록"이 주문서에 자동으로 생깁니다. 마우스로 그려도 코드가 만들어지므로 코딩 학습이 이어집니다.
- **주문 줄이기 마법**: 같은 그림을 반복 블록을 써서 더 짧은 코드로 바꿔 보여줍니다 (효율적인 알고리즘 생각하기).
- 실행 취소 / 다시 실행, 작품 이름, 저장, 보관함(열기·PNG·삭제 확인), **PNG 다운로드**

### C. 움직이는 픽셀 극장 (애니메이션)
- 프레임 추가 / 복사 / 삭제 / 순서 바꾸기 (최대 24장), **프레임마다 명령 블록 유지**
- 이전 프레임을 반투명하게 보여주는 **어니언 스킨**
- 미리보기 극장에서 재생 / 정지, 속도(느리게·보통·빠르게), 반복 재생
- 예시 템플릿 5종: 눈 깜빡이는 고양이, 통통 뛰는 토끼, 반짝이는 별, 피어나는 꽃, 걷는 공룡 (예시도 모두 명령 블록으로 들어 있어 코드를 살펴볼 수 있습니다)
- 저장 / 보관함, **GIF 내보내기**(외부 라이브러리 없이 직접 구현한 인코더), **프레임 모음(스프라이트 시트) PNG**

## 4. 코딩 블록과 실행 규칙

| 블록 | 하는 일 |
|---|---|
| 위로 / 아래로 / 왼쪽으로 / 오른쪽으로 1칸 | 펜 위치만 옮깁니다 (칠하지 않음) |
| 색칠하기 | 펜이 있는 칸을 지금 펜 색으로 칠합니다 |
| 지우기 | 펜이 있는 칸을 비웁니다 |
| 색 바꾸기 | 다음부터 칠할 펜 색을 바꿉니다 |
| N번 반복하기 | 안에 넣은 블록들을 N번 실행합니다 (1~20번, 5겹까지 중첩 가능) |

- 좌표는 왼쪽 위가 **(0,0)**. 펜은 (0,0)에서 출발하고, 처음 칸을 자동으로 칠하지 않습니다.
- 실행할 때마다 도화지를 새로 시작하므로 이전 결과와 섞이지 않습니다.
- 도화지 밖으로 나가려 하면 그 블록에서 멈추고 *"앗! 마법 펜이 도화지 밖(오른쪽)으로 나가려고 해요!"* 처럼 안내하며, 해당 블록을 빨갛게 표시합니다.
- 안전 제한: 한 번 실행에 최대 6000단계, 반복 최대 20번, 중첩 5겹 → 앱이 멈추지 않습니다.
- 실행 도구: 실행 / 일시정지 / 이어서 실행 / **한 단계씩** / 처음부터 / 결과 지우기 / 속도 5단계
- 실행 중: 지금 실행하는 블록 강조(◀ 표시 + 테두리), 반복 블록에 "2/5번째" 표시, 펜 위치·펜 색·단계 수 표시

### 블록 조작
- **눌러서 넣기**: 블록 상자의 블록을 누르면 주문서의 "다음 블록은 여기에" 위치에 들어갑니다. 반복 블록을 넣으면 바로 그 안에 넣을 수 있게 됩니다.
- **끌어서 옮기기**: 블록을 끌어서 순서를 바꾸거나 반복 블록 안/밖으로 옮깁니다. 블록 상자 위에 놓으면 버려집니다. (터치 화면에서는 블록 왼쪽의 점 6개 손잡이를 끌어 주세요.)
- 드래그가 어려운 학생: 블록을 눌러 선택한 뒤 ▲▼ 버튼으로 옮길 수 있습니다.
- 키보드: 선택한 블록에서 `Delete` 삭제, `Alt + ↑/↓` 이동

## 5. 저장에 대해 (선생님 꼭 읽어 주세요)

- 작품·미션 진행·설정은 **이 컴퓨터, 이 브라우저의 로컬 저장소(localStorage)** 에 저장됩니다. 새로고침하거나 브라우저를 다시 열어도 남아 있습니다.
- 다른 컴퓨터와는 공유되지 않습니다. 컴퓨터실에 **재부팅 시 초기화 프로그램**이 있다면 수업이 끝나기 전에 **PNG / GIF 로 내려받아** 두도록 안내해 주세요.
- 브라우저의 시크릿(사생활 보호) 창에서는 창을 닫으면 저장 내용이 지워집니다.
- 저장하지 않은 작품이 있을 때 모드를 바꾸거나 다른 작품을 열면 저장할지 물어봅니다. (저장하지 않아도 같은 컴퓨터에서는 작업 중이던 내용이 임시로 유지됩니다.)

## 6. 수업 활용 팁

- 상단 오른쪽 **전체 화면** 버튼으로 대형 화면 시연
- 미션 시작 시 나오는 **개념 카드**로 오늘의 개념을 짧게 소개
- 속도를 "아주 느리게"로 두거나 **한 단계씩** 버튼으로 순차 실행을 함께 따라가 보기
- 미션 12(디버깅)는 일부러 고장 난 코드가 들어 있습니다. "한 단계씩"으로 버그를 찾는 활동에 좋습니다.
- 소리는 오른쪽 위 스피커 버튼으로 끌 수 있습니다.

## 7. 새 미션 추가하기 (선생님·개발자용)

`src/data/missions.ts` 에 미션을 추가합니다. 목표 그림은 글자 그림으로, 모범 답안은 짧은 표기법으로 적습니다.

```ts
art: ['.r.r.', 'rrrrr', '.rrr.', '..r..'],   // '.' = 빈칸, 글자 = 색 (r 빨강, o 주황, y 노랑, g 초록, m 민트, b 파랑, p 보라, k 분홍, n 갈색, s 살구, w 하양, d 먹색)
solution: 'R P R R P D 4[P L] P',             // U D L R 이동, P 색칠, E 지우기, c:색 색 바꾸기, 3[ ... ] 반복
```

`npm test` 를 실행하면 모든 미션의 모범 답안이 실제로 목표 그림을 완성하는지 자동으로 검사합니다.

```
pixel-magic-lab/
├─ index.html
├─ public/favicon.svg
├─ src/
│  ├─ engine/           ← UI와 분리된 코딩 실행 엔진

│  │  └─ palette.ts     12색 팔레트
│  ├─ data/             미션 12개, 애니메이션 예시 5종
│  ├─ lib/              실행 재생기(useRunner), 실행 취소, 저장, 효과음, PNG/GIF 내보내기
│  ├─ components/       블록 편집기, 픽셀 도화지(SVG), 실행 막대, 팝업, 아이콘
│  ├─ modes/            세 가지 모드 화면

└─ dist/                배포용 빌드 결과
```

## 9. 구현 상태

모두 실제로 동작합니다.

- ✅ 실행 엔진 (순차, 반복, 중첩 반복, 오류, 안전 제한)
- ✅ 블록 편집 (클릭 추가, 드래그 이동, 버튼 이동, 삭제, 반복 횟수, 색 선택, 반복 안에 넣기, 실행 취소)
- ✅ 미션 12개 + 성공 판정 + 힌트 + 개념 카드 + 별·도장·칭호 + 진행 저장 + 선생님 모드
- ✅ 단계 실행·일시정지·속도·실행 블록 강조·펜 위치·오류 위치/이유 표시·목표 비교
- ✅ 자유 공방: 크기 선택, 팔레트, 그리기 도우미, 주문 줄이기, 저장/불러오기/삭제, PNG
- ✅ 극장: 프레임 편집, 어니언 스킨, 재생, 저장/불러오기, 예시 5종, GIF, 스프라이트 PNG
